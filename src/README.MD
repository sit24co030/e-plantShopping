# Paradise Nursery Shopping Application

## About the Project
Paradise Nursery is a React-based plant shopping application that helps users browse plants and manage their shopping cart.

## Features
- Browse plants from different categories.
- View plant images, names, and prices.
- Add plants to the shopping cart.
- Increase and decrease plant quantities.
- Remove plants from the cart.
- View item subtotals and the total cart amount.
- Navigate between Home, Plants, Cart, and About Us pages.
- Display a checkout message when Checkout is clicked.

## Technologies Used
- React
- JavaScript
- Redux Toolkit
- React Redux
- React Router
- CSS
- Vite

## How to Run
1. Install Node.js.
2. Open the project folder in the terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.

## Project Purpose
This application demonstrates React components, routing, state management, and shopping cart functionality as part of a Coursera project.
