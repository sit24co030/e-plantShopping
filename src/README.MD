# Paradise Nursery Shopping Application

## About the Project
Paradise Nursery is a React-based plant shopping application that allows users to explore plants and manage their shopping cart.

## Features
- Browse plants from different categories.
- View plant images, names, and prices.
- Add plants to the shopping cart.
- Increase or decrease plant quantities.
- Remove plants from the cart.
- View individual subtotals and the total cart amount.
- Navigate between Home, Plants, Cart, and About Us pages.
- Display a checkout message when the Checkout button is clicked.

## Technologies Used
- React
- JavaScript
- Redux Toolkit
- React Redux
- React Router
- CSS
- Vite

## How to Run the Project

1. Install Node.js.
2. Open the project folder in the terminal.
3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local address shown in the terminal.

## Project Purpose
This application was developed as part of the Coursera shopping application project to demonstrate React components, state management, routing, and shopping cart functionality.
